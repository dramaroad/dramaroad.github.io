طريقة الاستبدال على GitHub من الموبايل:
1) افتح Repository: -drama-road-kids
2) اضغط Code ثم زر ... بجانب الزر الأخضر Code.
3) اختر Upload files / Add files.
4) اضغط choose your files.
5) من مجلد drama-road-kids-final-upload اختر جميع الملفات الموجودة في هذا المجلد دفعة واحدة.
6) GitHub سيظهر تحذير أن بعض الملفات موجودة مسبقاً؛ هذا طبيعي، اتركها ليتم استبدالها.
7) انزل إلى Commit changes.
8) اختر Commit directly to the main branch.
9) اضغط Commit changes.
10) انتظر 1-3 دقائق ثم افتح رابط GitHub Pages واعمل Refresh.

ملاحظة مهمة:
الصور والملفات في هذه الحزمة كلها في الجذر (بدون مجلد assets) لتسهيل رفعها من iPhone.
الإضافات الجديدة من قسم الإدارة تُحفظ على نفس الجهاز حالياً. ربط قاعدة بيانات سحابية يحتاج خطوة لاحقة.
