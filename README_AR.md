# Drama Road Kids — النسخة الكاملة الأولى

موقع عربي RTL بتصميم أبيض مع هوية Drama Road (أحمر / أسود / أبيض) لعرض مواهب قسم الأطفال واليافعين أمام شركات الإنتاج.

## الصفحات
- `index.html` الصفحة الرئيسية.
- `talents.html` البحث والفلترة حسب الاسم، الجنس، العمر، مدة الدراسة والمهارات.
- `profile.html?id=...` ملف مستقل لكل موهبة.
- `projects.html` جميع الأعمال والمشاريع المضافة.
- `about.html` عن المنصة والمعهد.
- `contact.html` نموذج طلب Casting تجريبي.
- `admin.html` لوحة إدارة لإضافة وتعديل الأطفال والمشاريع.

## البيانات الحالية
تم إدخال 20 موهبة بالصور والأعمار ومدد الدراسة المرسلة في المحادثة. تم تسجيل:
- زهير اللحام: 190 سم.
- محمود علي جناد: مهارة الغناء.

لم يتم افتراض جنس أي طفل/طفلة من الصورة أو الاسم. حقل الجنس موجود ويمكن تحديده من لوحة الإدارة، وبعدها تعمل فلترة مثل «بنت + 16 سنة» بدقة.

## ملاحظة تقنية مهمة
هذه النسخة Static وتخزن إضافات لوحة الإدارة في `localStorage` على الجهاز والمتصفح المستخدم. وهي تعمل بالكامل محلياً كنموذج إنتاجي للواجهة. لكي تصبح إضافات الإدارة مرئية فوراً لكل زوار الموقع ومن كل الأجهزة، يلزم ربط قاعدة بيانات سحابية + تسجيل دخول للإدارة (مثل Supabase/Firebase أو Backend خاص).

## النشر
المجلد جاهز للنشر مباشرة على GitHub Pages أو Netlify أو Vercel أو أي استضافة Static. وجود ملف `.nojekyll` يجعله مناسباً لـ GitHub Pages.
